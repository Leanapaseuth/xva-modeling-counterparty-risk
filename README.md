# XVA Modeling & Counterparty Risk

## About the project

This project was carried out as part of the **Industrial Innovation Project at ESILV**.

The objective was to understand and model the main **XVA indicators** used in financial institutions to take into account counterparty risk and other costs related to derivative valuation.

The project focuses on:

* CVA — Credit Valuation Adjustment
* DVA — Debit Valuation Adjustment
* FVA — Funding Valuation Adjustment
* KVA — Capital Valuation Adjustment
* MVA — Margin Valuation Adjustment

## What we did

We developed a **Python prototype** based on Monte Carlo simulations to simulate interest-rate scenarios, revalue derivative products and estimate their future exposures.

The model uses two correlated interest-rate factors inspired by the **Hull–White model**, representing the €STR discounting curve and the Euribor 6M projection curve.

The simulated scenarios are then used to calculate exposure profiles and simplified XVA indicators.

## Products

The model includes several interest-rate products:

* Interest Rate Swap (IRS)
* Zero-Coupon Bond
* Forward Rate Agreement (FRA)
* Cap
* Swaption

This allowed us to compare the exposure profiles generated by different types of products.

## Dashboard

We also developed an interactive dashboard connected to the Python model.

The dashboard allows the user to:

* Select a financial product
* Change parameters such as notional, rate and volatility
* Run the calculation
* Visualize the results through interactive charts

The frontend was developed with **React** and connected to the quantitative model through a local API.

## Validation

An Excel file was also created to check some of the numerical results produced by the model and compare them with the results displayed in the dashboard.

## Limitations

This is an academic project, so the model uses simplified assumptions compared with a production XVA framework used by financial institutions.

In particular, the default probabilities, FVA and KVA calculations are simplified, and the exposure is currently calculated instrument by instrument rather than on a fully aggregated portfolio.
